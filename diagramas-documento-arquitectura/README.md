# Diagramas del documento de arquitectura

Fuentes PlantUML (C4 y 4+1) asociadas a la sección de arquitectura del
documento del proyecto.

Los archivos `01`–`04` usan la librería [C4-PlantUML](https://github.com/plantuml-stdlib/C4-PlantUML)
(`!include` remoto).

| Archivo | Diagrama |
|---|---|
| `01-c4-contexto.puml` | C4 — Contexto |
| `02-c4-contenedores.puml` | C4 — Contenedores |
| `03-c4-componentes-api.puml` | C4 — Componentes de la API |
| `04-c4-codigo-disponibilidad.puml` | C4 — Código (cálculo de franjas) |
| `05-4plus1-escenarios.puml` | 4+1 — Escenarios |
| `06-4plus1-vista-logica.puml` | 4+1 — Vista lógica |
| `07-4plus1-vista-proceso.puml` | 4+1 — Vista de proceso |
| `08-4plus1-vista-desarrollo.puml` | 4+1 — Vista de desarrollo |
| `09-4plus1-vista-fisica.puml` | 4+1 — Vista física |
