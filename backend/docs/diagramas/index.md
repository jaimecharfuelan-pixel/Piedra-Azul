# Diagramas de clases

Fuente de verdad: `DiagramaDeClasesMonolito2026-2.mmd` (en esta carpeta).

Por límite de tamaño de Mermaid en Draw.io, el diseño está partido en:

| Archivo | Contenido |
|---|---|
| `00-VistaGeneralModulos.mmd` | Vista C4 de módulos y puertos |
| `01-SharedKernel.mmd` | Shared kernel |
| `02-ModuloIdentidadAcceso.mmd` | Identidad |
| `03-ModuloGestionPersonas.mmd` | Personas |
| `04-ModuloConfiguracionDisponibilidad.mmd` | Disponibilidad (RF3) |
| `05a-ModuloCitas-Dominio.mmd` | Citas — dominio |
| `05b-ModuloCitas-AplicacionInfra.mmd` | Citas — aplicación/infra |
| `06-ModuloNotificaciones.mmd` | Notificaciones |
| `07-InfraestructuraTransversal.mmd` | Infra transversal |

Insertar en Draw.io: `Extras > Editar diagrama...` o `Insertar > Avanzado > Mermaid`.
